Get started

Install

Git Replay ships as the npm package git-replay-cli — install it once, then run it from inside any repository. The deterministic features all work offline.

npm Install globally
npm install -g git-replay-cli

Puts the git-replay command (and a git-replay-cli alias) on your PATH.

npx Run without installing
npx git-replay-cli timeline

Fetches and runs the latest published version on demand.

source Clone & link
git clone https://github.com/haileamlakwalelige/git-replay.git

Then cd git-replay && npm install && npm link.

Then, inside any repository
git-replay serve
View on npm Source on GitHub

Naming note. Git 2.42+ ships an experimental builtin called git replay, which Git prefers over external executables — so invoke the git-replay command directly.
